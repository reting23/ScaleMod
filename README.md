  # ScaleMod

  **Butt and Boobs Slider for Momulator**

  Windows · Update 42 · Momulator

ScaleMod is a modification of [Momulator]([https://captainelderly.itch.io/momulator-alpha]). It brings sliders for the Booty and the Boobs

AI was involved throughout this project, including implementation and testing.

## Play

You need Windows 10 or Windows 11, Momulator, and UE4SS from [this]([https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest])

1. Open this repository's **Releases** and download `ScaleMod.zip`.
2. extract the ZIP, and put the files from the ScaleMod zip file and put it in Momulator0.0.2.0\Windows\Momulator\Binaries\Win64
3. Run the game
4. Press P then go to Settings -> Content -> and you should see 2 Sliders named Booty and Boobs.
